# v1.0.0 — Enterprise Playwright Quality Engineering Reference

This first stable portfolio release demonstrates a governed Playwright + TypeScript test architecture suitable for Senior SDET, Test Architect, Automation Architect and Quality Engineering Architect review.

## Included evidence

- UI, API, integration, accessibility and focused visual-regression suites
- strict TypeScript, typed configuration, Zod contracts, fixtures, clients and test-data factories
- Chromium, Firefox and WebKit execution with parallelism, retries and three-way sharding
- screenshots, video, traces, structured logs, HTML, JSON, JUnit and optional Allure reporting
- deterministic credential-free local API execution
- GitHub Actions workflows, Docker execution and a configurable release quality gate
- a 66-second recruiter walkthrough and a five-minute verification path

## Verification

```bash
npm ci
npx playwright install chromium
cp .env.example .env
npm run validate
npm run test:api:local
```

## Scope and limitations

This is a reference implementation using synthetic and public demo targets. It is not a claim about a customer production system. Browser-based SauceDemo scenarios require runtime credentials; the local API path remains credential-free and deterministic.
