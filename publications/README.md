## Reference Implementations

The primary open-source [Playwright Enterprise Test Framework](https://github.com/ashokmanohar-ai/playwright-enterprise-test-framework) demonstrates strict TypeScript, typed fixtures, reusable authentication state kept outside source control, UI/API/integration/accessibility/visual testing, cross-browser execution, screenshots, video, traces, structured logs, GitHub Actions and release quality gates.

The supporting [Enterprise AI Quality Engineering Platform](https://github.com/ashokmanohar-ai/enterprise-ai-quality-engineering-platform) demonstrates MCP protocol and business-rule testing, including startup/discovery, schemas, valid and invalid calls, cross-account denial, confirmation behavior, resources, prompts and agent interpretation.
